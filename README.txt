# Responsive Design Assignment

## Files
- `index.html` — page content and six destination cards
- `style.css` — mobile-first styles and the two required media queries

## Required responsive behavior
- **Mobile:** below 772px, each `.place` card is full width and stacks vertically.
- **Tablet:** at 772px and above, cards use `display: inline-block` and `width: 45%`; images are limited to `max-height: 30vh`.
- **Large screen:** at 998px and above, cards use `width: 30%`.

## How to check
1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Resize the browser or use Developer Tools → device toolbar.
4. Test widths around 390px, 800px, and 1100px.

Images are loaded from Unsplash, so an internet connection is needed to display them.
